## Что где смотреть

- **Если интересна веб-разработка и магазины:** Content System. Модель данных (каталог, товары с атрибутами, медиа), разграничение доступа между пользователями, сквозная типизация от базы до UI, конструктор страниц.
- **Если интересна работа с данными и интеграции:** Contenter. Превью парсинга в реальном браузере, компиляция декларативных правил в JS, динамическая схема БД, очередь ссылок в базе.
- **Если интересна архитектура как таковая:** L2Train. Событийная шина на декораторах, кодогенерация типизированного API, сценарии-плагины, разделение «оркестратор / исполнитель», а также таблица того, что не сработало.

## Архивы

Архивы защищены паролем, пароль передаю отдельно. Внутри исходный код без `node_modules`, истории git и секретов; шаблоны настроек лежат в файлах `.env.example`. Архивы открываются стандартными средствами Windows и macOS.
